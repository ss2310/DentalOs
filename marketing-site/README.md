# Marketing site — themaskedmarketers.com

One self-contained page (`index.html`) — no build step, no dependencies
beyond Google Fonts.

## Deploy on Netlify (2 minutes)

1. Go to https://app.netlify.com/drop
2. Drag this `marketing-site` folder onto the page.
3. Site is live on a `*.netlify.app` URL. Add your domain:
   Site settings → Domain management → Add `themaskedmarketers.com`
   (Netlify shows the DNS records to set at your registrar).

## Things you may want to edit (all in index.html)

- **App links**: every CTA points to `https://app.themaskedmarketers.com`
  (login) and `https://app.themaskedmarketers.com/signup` (trial). Search
  and replace if the subdomain differs.
- **Pricing**: matches pricing v2 (migration 047) — Growth ₹2,999/mo,
  annual ₹29,990, trial 30 credits / 2 scans / 1 audit, packs ₹549–1,699.
  If prices change in the app, change them here too.
- **Stats band**: the four proof numbers are from public dental-marketing
  research (review readership, local-search share, no-show reduction).
